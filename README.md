# Подбор вин

Приложение использует обученный пайплайн из `model.joblib` и сохранённую тестовую выборку. Для запуска нужен Python 3.12.

```bash
cd wine-app-hw3
python -m pip install -r requirements.txt
streamlit run app.py
```

Слайдер в боковой панели задаёт порог для одиночного и пакетного прогнозов, а также для матрицы ошибок и метрик. Пакетный CSV должен содержать 12 столбцов с теми же именами, что в `test.csv`, кроме `target`.

`st.cache_resource` хранит один объект модели на сервере. `st.cache_data` хранит копии таблицы и вычисленных вероятностей. Если вызывать `joblib.load` без кэша, Streamlit снова прочитает модель с диска при каждом изменении слайдера.

Для публикации на Streamlit Community Cloud загрузите папку в репозиторий GitHub, где у вас есть права администратора. На [share.streamlit.io](https://share.streamlit.io) создайте приложение из этого репозитория, укажите ветку `main` и файл `app.py`. Выберите Python 3.12 в дополнительных настройках. Community Cloud установит зависимости из `requirements.txt`.
